1 The Big Picture — What Are We Building & Why?

Welcome to the TRACE-X team! If you are a beginner, here is the simplest way to think about what this project does:

🎯 The Problem We Are Solving (SIH26151)

Cyber criminals and nation-state Advanced Persistent Threat (APT) groups operate in the shadows. They use the Dark Web (Tor) to communicate, cryptocurrency (Ethereum) to transfer funds, malware command servers to coordinate attacks, and PGP encryption keys to sign messages. Because these activities are scattered across completely different networks, investigators struggle to connect the dots.

TRACE-X solves this by acting as an intelligent correlation engine. It ingests pieces of evidence from all these sources, maps them into unified digital entities, calculates how likely they are related using mathematical confidence scores, and visualizes the connections on an interactive graph.

Step 1

Ingest

Collect raw logs from Ethereum, threat intel (MISP), dark web forums, and PGP keyrings without altering the original files.

Step 2

Correlate

Discover deterministic links (e.g. shared IPs, wallet transactions, co-occurring hashes) and calculate confidence scores.

Step 3

Investigate

Empower human cyber investigators with an interactive graph, AI Copilot, and court-ready forensic reports.

2 The Forensic Boundary Principle (Why We Don't "Hack Tor")

⚖️ Crucial Concept for Evaluators & Judges

Judges at the Smart India Hackathon (NTRO problem) will test whether our solution understands legal forensic boundaries. A tool that claims to magically break Tor encryption or reveal names of random citizens would be fraudulent and illegal. TRACE-X strictly separates facts from theories.

TRACE-X classifies all digital telemetry into four distinct levels of confidence:

Evidence Level Confidence What It Means in Plain English Real Example in TRACE-X
1. Observed Evidence 100% (1.0) A mathematically or cryptographically verified digital event. No guessing involved. Wallet A sent 0.5 ETH to Wallet B in Block #25947413; or CIRCL PGP key matches fingerprint CA57....
2. Inferred Relationship 60% – 75% Two entities share digital infrastructure or patterns, suggesting common control. Two distinct phishing domains (noticias-al-dia.com and justiciaparatodos.org) resolve to the exact same C2 IP: 198.12.150.249.
3. Strong Correlation 80% – 95% Indicators verified across multiple independent datasets (multi-source boost). A domain found in a Dark Web forum discussion matches an active C2 domain in a MISP malware threat advisory.
4. Verified Attribution Requires Legal KYC Asserting that a digital entity belongs to a real-world human being. Asserted only when judicial orders, ISP subscriber records, or exchange KYC documents are legally attached. In our demo, this is clearly tagged [SYNTHETIC AUTHORIZED EVIDENCE].

5 Step-by-Step Architecture Flow — How the Code Works

Here is the full journey of a piece of data from the raw disk file to the investigator's web browser:

[1. RAW FILES] data/blockchain/transactions.csv | data/cti/raw/packrat.json | data/darkweb/safe_corpus.json │ ▼ [2. MODULAR INGESTION ADAPTERS] (backend/app/adapters/) - BlockchainAdapter: Parses transfers, calculates Wei->ETH, hashes each row with SHA-256 - CtiAdapter: Extracts domains, hostnames, IPs, hashes, and MITRE TTPs - DarkWebAdapter: Extracts thread titles, timestamps, masked author tokens - PgpAdapter: Parses fingerprints, key IDs, and RFC 4880 armor headers │ ▼ [3. NORMALIZATION & CANONICAL ENTITIES] (backend/app/engine/normalizer.py) - Resolves raw indicators into standardized IDs: ENT-WALLET-0x51c7... | ENT-IP-198.12.150.249 | ENT-DOM-noticias-al-dia.com - Computes SHA-256 integrity hash for unalterable chain-of-custody │ ▼ [4. CORRELATION ENGINE] (backend/app/engine/correlation.py) - Scans all entities for shared attributes: * TRANSACTS_WITH: On-chain fund flow between sender and recipient * SHARED_INFRASTRUCTURE: Multiple domains resolving to the same IP * REFERENCES: Threat actor referenced in CTI advisories or leak threads - Evaluates confidence score using explainable weighting formula │ ▼ [5. GRAPH TOPOLOGY & FASTAPI REST API] (backend/app/engine/graph_engine.py & /api/) - Builds NetworkX graph object (calculates degree centrality, shortest paths) - Serves JSON payloads through FastAPI endpoints (/api/dashboard, /api/graph, etc.) │ ▼ [6. REACT SOC FRONTEND] (frontend/src/) - Renders interactive Cytoscape.js canvas with clickable edge rationales - Displays real-time telemetry, 360° dossiers, AI Copilot, and report generator

6 Explainable Scoring Engine — How TRACE-X Calculates Confidence

Judges love when an AI system can explain WHY it made a decision rather than acting as an opaque black box. In TRACE-X, every connection has a deterministic score calculated via this formula:

📐 The Mathematical Confidence Formula

Final Confidence = min(1.0, BaseWeight × MultiSourceBoost × ProvenanceFactor)

Factor Weight Value Forensic Logic
EXACT_CRYPTO_HASH 0.95 SHA-256 or MD5 collision is mathematically near-impossible.
EXACT_PGP_FINGERPRINT 0.95 Cryptographic fingerprint uniquely identifies the public key.
EXACT_WALLET 0.90 Direct Ethereum address interaction recorded immutably on-chain.
SHARED_INFRASTRUCTURE 0.75 Multiple malicious hostnames resolving to the exact same hosting IP.
APPEARS_IN_LEAK 0.65 Textual mention of an entity in a leaked forum breach thread.
MULTI_SOURCE_BOOST × 1.25 Crucial multiplier: If an indicator appears in 2 or more independent sources (e.g. MISP CTI + Dark Web), its confidence score is boosted by 25%.

7 How to Run TRACE-X on Any Machine (Windows, Mac, Docker)

🪟 On Windows

Method A (Easiest): Double-click run.bat in Windows File Explorer!

Method B (PowerShell): 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\run.ps1

Opens backend on port 8000 and frontend on port 5173 automatically.

🍎 On macOS / Linux

Run the 1-click startup shell script: 

chmod +x run.sh
./run.sh

Starts both Uvicorn and Vite. Press Ctrl+C anytime to stop cleanly.

🐳 With Docker

No Python or Node installation required: 

docker compose up --build -d

Builds multi-stage container and exposes port 80 / 8000.

🌐 Access Points Once Running

  • Investigator Web UI: http://localhost:5173 (or http://localhost:8000 in Docker)
  • Backend REST API: http://localhost:8000
  • Interactive Swagger API Docs: http://localhost:8000/docs

9 Beginner Cyber & Tech Terms Glossary

APT (Advanced Persistent Threat)

A sophisticated, long-term cyber attack campaign typically conducted by a nation-state or well-funded cybercriminal organization. (Example: Packrat).

C2 (Command and Control)

The central server or IP address used by hackers to send instructions to infected computers and receive stolen data. (Example: 198.12.150.249).

IOC (Indicator of Compromise)

Digital evidence that an attack occurred, such as a malicious IP address, a phishing domain, or a file hash.

MISP

Malware Information Sharing Platform. An open-source threat intelligence sharing platform used by cybersecurity teams worldwide.

SHA-256

A cryptographic hashing algorithm that creates a unique 64-character digital fingerprint of any data. If even 1 character changes, the hash changes completely.

RPC (Remote Procedure Call)

A protocol that allows our application to ask a live blockchain node (like Alchemy) for real-time account balances and transaction data.

Cytoscape.js

The high-performance graph theory library used by TRACE-X to render nodes (entities) and edges (relationships) on the interactive map canvas.

Canonical Entity ID

A normalized identifier like ENT-WALLET-... or ENT-IP-... used by TRACE-X so that the same indicator is never duplicated in the graph.
