1 The Big Picture: What Problem Does TRACE-X Solve?

💡 The Real-World Detective Analogy

Imagine a cyber criminal group operating across the world. They don't use their real names or real email addresses. Instead, they leave pieces of digital footprints in completely separate places:

  • They pay for bulletproof hosting using an Ethereum cryptocurrency wallet.
  • They infect victims using malware hosted on a Command & Control (C2) server IP.
  • They brag about their attacks in underground Dark Web forums.
  • They sign private security messages using an encrypted PGP digital signature.

Normally, an investigator has to open 4 separate websites and manually try to remember: "Wait, did this IP address appear in that dark web leak? Does this Ethereum wallet link to that phishing site?"

🎯 What TRACE-X Does Automatically

TRACE-X is an automated digital investigation board. It pulls in all these clues, standardizes them, calculates mathematical connection probabilities, and draws a visual spider web on an interactive map so investigators can see the full threat-actor network in seconds.

2 The Forensic Boundary Principle (Why We Don't "Hack Tor")

⚖️ Essential Rule for Evaluators & Judges

Judges at the Smart India Hackathon (NTRO problem) want to know: "Does this team understand real cybersecurity law and forensics?"
Any tool claiming to magically reveal real names of anonymous Tor users with a button click is fake. The Tor network uses multi-layered mathematical encryption. TRACE-X wins because it strictly respects four scientific levels of evidence:

Evidence Level Confidence What It Means in Plain English Real Example in TRACE-X
1. Observed Evidence 100% (Fact) A mathematical or cryptographic event recorded directly in data. Zero guessing. Wallet A sent 0.5 ETH to Wallet B in Ethereum Block #25947413.
2. Inferred Relationship 70% – 85% Two entities share digital infrastructure or patterns, showing strong coordination. Two phishing websites (noticias-al-dia.com & justiciaparatodos.org) resolve to the exact same IP 198.12.150.249.
3. Multi-Source Correlation 85% – 95% An indicator verified across multiple independent feeds (receives a 25% confidence boost). A domain discussed in Dark Web forum database leaks matches an active C2 in a MISP threat advisory.
4. Verified Attribution Legal Subpoena Required Asserting that a digital indicator belongs to a real physical person. Requires court orders, judicial subpoenas, or exchange KYC records. (In our demo, this is clearly tagged [SYNTHETIC AUTHORIZED EVIDENCE] to prove the workflow without fabricating innocent citizens).

6 The Confidence Score Formula (No Black Boxes)

In forensics, you must be able to justify WHY two clues are connected. TRACE-X never uses random guesses. Every connection uses this exact formula:

📐 Mathematical Confidence Formula

Final Confidence = min(1.0, BaseWeight × MultiSourceBoost × ProvenanceFactor)

Rule Name Weight Value Why This Weight Was Chosen
EXACT_CRYPTO_HASH 0.95 Cryptographic hash collision (SHA-256) is mathematically impossible.
EXACT_PGP_FINGERPRINT 0.95 PGP key fingerprint uniquely identifies the public key author.
EXACT_WALLET 0.90 Direct Ethereum address interaction is immutable on the blockchain ledger.
SHARED_INFRASTRUCTURE 0.75 Two or more phishing domains resolving to the same server IP.
APPEARS_IN_LEAK 0.65 An entity mentioned inside an underground breach forum thread.
MULTI_SOURCE_BOOST × 1.25 The Golden Multiplier: If an indicator appears in 2 or more independent sources (e.g. MISP + Dark Web), its confidence is multiplied by 1.25!

9 Simple Beginner Glossary (Cyber Jargon Made Easy)

APT (Advanced Persistent Threat)

A sophisticated, organized hacking group that conducts long-term espionage campaigns. Example: Packrat.

C2 (Command and Control)

A central computer server used by attackers to send commands to infected machines and receive stolen data.

IOC (Indicator of Compromise)

A piece of digital evidence showing an attack happened—such as a malicious IP address, malware hash, or phishing domain.

SHA-256 Hash

A unique 64-character digital fingerprint. If even a single comma in a file changes, the hash changes completely.

RPC (Remote Procedure Call)

A live connection that allows our app to talk directly to an Ethereum blockchain node (Alchemy) to get real-time balances.

Cytoscape.js

The graph theory engine we use to draw interactive circles (nodes) and connecting lines (edges) on our correlation map.
